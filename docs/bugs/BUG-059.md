# BUG-059 — IAT patch crossing a page boundary faulted

**Status:** CLOSED (TESTED) — 2026-10-17, wave W4
**Found by:** curl.exe SIGSEGV inside the loader (mov [rdx],rcx at
image offset 0x3a8ffc)
**Files:** src/loader/loader.c

## Root cause
curl's IAT ends exactly at page offset 0xFFC; the 8-byte store wrote 4
bytes into the NEXT page, which iat_page_ensure_writable had not unlocked.

## Fix
Both code- and data-import patch sites ensure writability of the second
page when (addr & 0xFFF) + 8 > 0x1000.
