## Analysis

- SW-807 located a NULL function pointer stored in .data at 0x14008a8e8 — a
  callback table slot that Windows fills at load time but the loader leaves
  NULL (an import that resolved to nothing, or a CRT initializer that never
  ran). puttygen calls it unconditionally.
- No stub was called before the fault (stub_calls=0), so the NULL is written
  by guest data initialization, not by an unresolved IAT slot.
- Next lever: dump .data 0x14008a8e8's neighborhood at load time, identify the
  relocation/init that should populate it, and either implement the missing
  initializer or resolve the correct import into it.
