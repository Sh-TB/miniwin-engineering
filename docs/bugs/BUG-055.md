# BUG-055 — strdup/_wcsdup/_fullpath memory invisible to the allocation registry

**Status:** CLOSED (TESTED) — 2026-10-17, wave W4 (TASK-OPENSRC battery)
**Found by:** jq.exe filters (exit 4 HEAP-TRAP "free of untracked/bad ptr")
**Files:** src/loader/loader.c

## Root cause
`mw__strdup` returned glibc `strdup()` memory that was never entered into
the W3 allocation registry. jq frees strdup'd parser strings through
`free()`; `mw_free` saw an untracked pointer and trapped (exit 4).
`mw__wcsdup` had the same hole (plus a 4-byte-wchar size computation) and
`mw__fullpath` malloc'd without registering when abs==NULL.

## Fix
All three allocate + copy + `w3_reg_add_sz()` like every other
guest-visible allocation; _wcsdup sizes in 2-byte guest units.
