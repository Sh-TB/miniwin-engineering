## OLEAUT32 fixed ordinals
7za.exe binds OLEAUT32 **entirely by ordinal** (2/4/6/7/9/10); 7z.exe adds
ordinal 149 (= SysStringByteLen). The import loop now maps known OLEAUT32
ordinals to names before the table lookup; unknown ordinals stay unresolved
with a stderr diagnostic line (`[WARN] unresolved: <name>`) added for
diagnosability.
