# BUG-033 — printf-family varargs cross the ms_abi → SysV boundary raw

**Status:** CLOSED (TESTED, 2026-10-15, EXP-040)
**Priority:** P0 (any rich printf format)
**Discovered:** appcompat sweep (t01 SIGSEGV in libc on `%f`; t02 passed
integer-only formats by structural luck)

## Symptom

`t01` crashed the moment a float conversion printed. The loader's
`mw_printf(fmt, ...)` (ms_abi) created a va_list and passed it directly to
glibc `vprintf`. glibc reads a SysV `va_list` = struct
`{gp_offset, fp_offset, overflow_arg_area, reg_save_area}`; the MS value it
received was a `char*` slot pointer, so `gp_offset` was the low 32 bits of a
stack address → wild reg-save-area reads → SIGSEGV inside libc.

## Root cause

Windows x64 varargs pass every argument as a uniform 8-byte slot
(integers/pointers directly, doubles as caller-spilled bit patterns);
SysV varargs use a register-save area (rdi..r9 + xmm0-7) with independent
GP/FP cursors and an overflow area. The two layouts are structurally
incompatible; an integer-only format can appear to work because slot order
and gp cursor coincidentally line up, but any FP conversion reads the XMM
area and faults.

## Fix (fmt-aware repack, loader.c BUG-033 block)

1. `mw_printf_classify(fmt, cls)` parses the format string (flags, width,
   `*`, precision, length modifiers, conversions) and classifies each
   consumed argument as GP or FP.
2. Variadic entries materialize the MS slots via ms va_arg
   (`double`/`long long`) into one uniform array.
3. `mw_printf_emit` synthesizes a faithful SysV va_list: gpv[0] = fmt (rdi
   consumed), varargs fill gpv[1..5] and xmm0-7 low 64 bits by class, the
   rest go to the overflow area **in call order** (SysV stack order).
4. Applied to `printf`, `fprintf`, `vfprintf` (the PE passes its own MS slot
   stream directly), and later `fwprintf` (wave 2, wide-format narrowing).
5. Bonus hardening: `_open/_wopen` converted from variadic to fixed-arg
   `mode` (APP-F-05b) — variadic ms_abi entry points are unsafe off the
   printf-family path.

## Verification

- t01: `float=3.14 sci=1.235e+04 g=0.0001` printed correctly; printf return
  count verified; PASS.
- t02/t03/t04/t07 (heavy mixed integer formats + many args): PASS.
- Regression 12/12; UPX G1 gate exit 0.
