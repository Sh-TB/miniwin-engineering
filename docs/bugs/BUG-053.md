# BUG-053 (OPEN) — wprintf/wide-%s output path prints raw 2-byte units

**Status:** OPEN — registered 2026-10-17 (TASK-OPENSRC-7ZIP)
**Observed:** `7za i` exits 0 but the Formats table renders as mojibake
("7 z BC AF ...") — format names are guest wide strings printed through
the narrow stdio bridge; every other byte pair is a NUL shown as a space,
and binary signatures leak through.
**Suspects:** printf-family repack (fmt-aware MS->SysV bridge) classifies
%s in wide formats ( / %s in wprintf) as narrow; needs UTF-16->UTF-8
conversion with the w3_utf16le_to_utf8 encoder and unit-count semantics.
