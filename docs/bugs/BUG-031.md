# BUG-031 — catch protocol-state validation fails: intermediate-frame cleanup never runs

**Status:** OPEN — READY (next task)
**Priority:** P0 (acceptance path frontier)
**Discovered:** 2026-10-15, post-BUG-030 live trace (EXP-038 §5)

## Symptom

BUG-030 delivers `sel=1` correctly; the landing pad 0x40331c takes the selector
branch (`call 0x4dfce0` executes), then the protocol-state validation fails:
the catch requires `check_var == 0x17 (23)` but it is `3 + 4*1 = 7`, because
the chain is `1 →(A's cleanup) 5 →(B's catch LP) 23` and A's cleanup never ran.
UPX prints its own assertion (`cxx_exception_handling_works … dt_check.cpp:
362`) and terminates → abort (exit 134).

## Root cause

`mw_RtlUnwindEx` jumps directly to the target landing pad and skips
intermediate-frame cleanups (documented simplification). Frame[3] (the thrower
0x401570) HAS a cleanup landing pad (0x4015A5, its LSDA cs_lp=0x35) that performs
protocol accounting (`check_var = 1 + 4*check_var` via 0x401550) and then calls
the continue-unwind helper 0x49d5c0. The UPX self-test is designed to pass only
if this cleanup executed in order.

## Protocol map (ground truth, EXP-038 §5.1 — input to the fix)

- Unwind-phase INSTALL at an intermediate frame ⇒ bridge re-raises
  `RaiseException(0x21474343, flags=1, 4 params {obj, est, LP, selector})`.
- Personality entry `code==0x21474343 && est==param[1]` ⇒ site-A' RtlUnwindEx
  resumes that frame's cleanup LP with `Rax=obj, Rdx=param[3]`.
- Cleanup LPs end with `0x49d5c0(obj)` ⇒ continue-unwind raise `0x120474343`
  (low dword = 0x20474343) with 4 params `{?, est_target, LP_target, selector}`
  from `obj+0x18/0x20/0x28` ⇒ same resume machinery for the next segment.
- **Design caution:** re-raises through the naked stub re-enter
  `mw_RtlDispatchException` from the C dispatcher stack (bridge → our
  mw_RtlUnwindEx C frame — no PE RUNTIME_FUNCTION) — the walk cannot traverse
  our C frames. Candidate designs: (a) the dispatcher itself honors
  `{0x21474343, 0x120474343}` 4-param records as resume commands (synthesized
  resume: Rip=param[2], Rax=obj, Rdx=param[3], Rsp=param[1]−alloc(param[2]));
  or (b) mw_RtlUnwindEx walks intermediate cleanups directly (personality calls
  with EH_UNWINDING) before resuming the target LP.
